## 🔗 Multi-Step Commands

JARVIS handles complex, multi-step commands automatically:

```
"Open Steam and start Counter-Strike 2"
→ 1. Launch Steam
→ 2. Wait for Steam to initialize
→ 3. Launch CS2 via Steam protocol
→ 4. Confirm success

"Search for the weather in Paris and open the forecast page"
→ 1. Get weather from API
→ 2. Open weather website for Paris

"Open YouTube, search for lofi music, and play the first result"
→ 1. Open browser
→ 2. Navigate to YouTube search
→ 3. Click first video result
```

## ⚙️ Settings & Control

- **Emergency Stop**: Click the red STOP button or say *"Stop"* during execution
- **Sandbox Mode**: Enable in Settings to test without executing commands
- **Confirmation**: Dangerous actions always ask for approval first
