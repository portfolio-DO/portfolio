PYTANIE 2: CO TO JEST SUPABASE I PO CO MI TO?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Supabase to darmowy serwis (jak chmura), który zapewnia:

1. KONTA UŻYTKOWNIKÓW
   Bez Supabase każdy mógłby kliknąć "zresetuj" w Chrome
   i stracić historię i ustawienia. Z Supabase:
   → logujesz się emailem i hasłem
   → Twoje dane są zapisane na serwerze
   → działają na każdym komputerze

2. BEZPIECZNE PRZECHOWYWANIE KLUCZA AI
   Klucz Anthropic (sk-ant-...) to jak hasło do konta —
   nie można go trzymać w kodzie rozszerzenia bo każdy
   mógłby go zobaczyć. Supabase Edge Functions trzymają
   go ukryty na serwerze.

3. LIMITY AI PO STRONIE SERWERA
   Gdyby limity (5/miesiąc darmowo) były tylko w
   rozszerzeniu, każdy mógłby je ominąć czyszcząc
   pamięć Chrome. Na serwerze Supabase tego nie da się obejść.

4. PREMIUM PRZYPISANE DO KONTA
   Gdy kupujesz Premium ($9/mies.), Stripe mówi Supabase:
   "ten email zapłacił". Supabase zapisuje to w bazie.
   Niezależnie na jakim komputerze się zalogujesz,
   Premium jest aktywne.

CZY SUPABASE JEST BEZPIECZNE?
  Tak — to jeden z największych i zaufanych serwisów
  dla deweloperów. Używają go tysiące firm. Twoje dane
  są szyfrowane. Darmowy plan wystarczy na ~50,000
  aktywnych użytkowników miesięcznie.

PYTANIE 3: CO TO SĄ "EDGE FUNCTIONS" I PO CO JE WDRAŻAĆ?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Edge Functions to małe programy działające NA SERWERACH
Supabase (nie na Twoim komputerze). Są trzy:

1. claude-proxy
   Kiedy klikasz "Wygeneruj odpowiedź AI", rozszerzenie
   NIE wysyła żądania bezpośrednio do Anthropic.
   Wysyła je do tej funkcji, która:
   → sprawdza czy masz limity (nie przekroczyłeś 5/mies.)
   → używa ukrytego klucza Anthropic
   → zwraca wygenerowaną odpowiedź
   Dzięki temu klucz Anthropic NIE jest widoczny w rozszerzeniu.

2. stripe-checkout
   Gdy klikasz "Przejdź na Premium", ta funkcja tworzy
   stronę płatności Stripe dla Twojego konta.

3. stripe-webhook
   Gdy Stripe potwierdza płatność, wysyła powiadomienie
   do tej funkcji. Ona aktualizuje Twoje konto w bazie
   danych na "premium".

JAK WDROŻYĆ (krok po kroku bez bólu):
  1. Zainstaluj Node.js z https://nodejs.org (wersja LTS)
  2. Otwórz Terminal (Windows: wyszukaj "cmd" lub "PowerShell")
  3. Wpisz: npm install -g supabase
  4. Wpisz: supabase login
     (otworzy przeglądarkę — kliknij Authorize)
  5. Wpisz: supabase link --project-ref TWOJ_REF
     (Ref znajdziesz w Supabase Dashboard → Project Settings → General)
  6. Przejdź do folderu z projektem: cd ścieżka/do/rrp-v3
  7. Wpisz:
     supabase functions deploy claude-proxy
     supabase functions deploy stripe-checkout
     supabase functions deploy stripe-webhook
  Gotowe! Funkcje działają teraz w chmurze Supabase.

  PO WDROŻENIU: nie musisz robić nic więcej. Działają same.

PYTANIE 4: CO TO JEST HTTP 429 I DLACZEGO SIĘ POJAWIA?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

HTTP 429 = "Too Many Requests" = za dużo prób.

Supabase ma limit: max 3 próby rejestracji na minutę
z jednego adresu IP. Jeśli próbowałeś rejestracji
kilka razy (np. testując), trafiłeś w ten limit.

CO ROBIĆ:
  → Odczekaj 1-2 minuty i spróbuj ponownie
  → Jeśli masz już konto — przejdź na zakładkę Logowanie
  → Jeśli hasło zostało zapisane — po prostu się zaloguj

W NOWEJ WERSJI: komunikat błędu jest teraz po polsku
i wyjaśnia dokładnie co się stało.

  Stripe automatycznie pobiera płatność co miesiąc
  i wysyła nowe powiadomienie do Supabase.

  lub napisz bezpośrednio do właściciela rozszerzenia.

do Twojego serwera (Supabase) gdy coś się dzieje.

Bez webhooka:
  Użytkownik płaci → Stripe wie → Supabase NIE wie
  → Premium się nie aktywuje

Z webhookiem:
  Użytkownik płaci → Stripe wysyła POST do Twojej funkcji
  → Supabase aktualizuje bazę → Premium aktywne

Ustawienie webhooka (jednorazowe):
  Stripe Dashboard → Webhooks → Add endpoint
  URL: https://TWOJ_PROJEKT.supabase.co/functions/v1/stripe-webhook
  I zaznaczasz 4 zdarzenia (opisane w KONFIGURACJA.txt).
  Stripe sam wysyła powiadomienia — nic więcej nie musisz robić.

PYTANIE 8: JAK DZIAŁA ROZSZERZENIE NA GOOGLE MAPS?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Rozszerzenie Chrome może "wstrzykiwać" kod JavaScript
do otwartych stron internetowych — to normalna,
bezpieczna funkcja przeglądarki.

Gdy otwierasz Google Maps:
  1. content.js "wchodzi" na stronę i szuka elementów HTML
     z recenzjami (po unikalnych klasach CSS Google'a)
  2. Pod każdą wykrytą recenzją dodaje pasek narzędzi
     z przyciskami "✦ AI" i "Szablon"
  3. Gdy klikasz przycisk, pyta popup (auth.js) czy masz limity
  4. Generuje odpowiedź i wstawia ją do pola odpowiedzi Google

DLACZEGO CZASEM NIE WYKRYWA RECENZJI:
  Google regularnie zmienia kod HTML Maps. Selektory CSS
  (np. ".MyEned", ".wiI7pd") mogą przestać działać.
  Rozwiązanie: wklej treść recenzji ręcznie w popup.
  (Planujemy regularnie aktualizować selektory)

DLACZEGO TRZEBA ODŚWIEŻYĆ STRONĘ PO INSTALACJI:
  Content scripts nie działają na kartach otwartych
  PRZED zainstalowaniem rozszerzenia. Wystarczy F5.

  Wartość (prawa kolumna) = Twój klucz

  CLAUDE_API_KEY         → sk-ant-api03-TwójKluczAnthropic

Jeśli chcesz po prostu UŻYWAĆ rozszerzenia bez całej
infrastruktury, oto minimum:

OPCJA A — Tylko szablony (bez AI):
  1. Załaduj extension/ w Chrome
  2. Zaloguj się (po konfiguracji Supabase)
  3. Używaj szablonów — działają bez żadnego API

OPCJA B — Szablony + AI z własnym kluczem:
  1. Kup klucz Anthropic na console.anthropic.com (~$5)
  2. Wpisz go w Ustawieniach rozszerzenia → "Własny klucz"
  3. Limity są śledzone lokalnie w Chrome
  → Nie potrzebujesz Supabase ani Stripe!

OPCJA C — Pełna wersja (konto + Premium):
  1. Skonfiguruj Supabase (30 min, tylko przeglądarka)
  2. Dodaj klucz Anthropic jako sekret Supabase
  3. Wdróż Edge Functions (10 min, terminal)
  4. Opcjonalnie: skonfiguruj Stripe dla Premium
  → Pełne możliwości: konta, limity serwerowe, Premium
